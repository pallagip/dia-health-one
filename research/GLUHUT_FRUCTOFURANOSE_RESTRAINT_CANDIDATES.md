# Bounded fructofuranose SMD restraint alternatives

**Date:** 4 November 2026  
**Status:** deposited atom-selection anomaly narrowed; no corrected production input selected  
**Scope:** public GluHUT fructofuranose steered-MD restraint only

## Question

The deposited fructofuranose guest centre-of-mass group contains the five furanose ring atoms plus hydrogen `H62`:

`C2, O5, C5, H62, C4, C3`

The earlier audit established that `H62` is isolated from the five selected ring atoms in the induced selected subgraph. The next question was whether this arose from reuse of numeric atom indices across incompatible carbohydrate templates, and which heavy-atom alternatives are chemically connected to the selected ring.

## Same numeric indices, different chemistry

The fructopyranose and fructofuranose restraint files use the same numeric `igr2` indices:

`160, 161, 162, 165, 169, 173`

Those indices do not preserve atom identity between the two GLYCAM templates:

| Index | Fructopyranose | Fructofuranose | Identity preserved? |
|---:|---|---|---|
| 160 | C2 | C2 | yes |
| 161 | O6 | O5 | no |
| 162 | C6 | C5 | no |
| 165 | C5 | H62 | **no; carbon becomes hydrogen** |
| 169 | C4 | C4 | yes |
| 173 | C3 | C3 | yes |

Element identity also fails at index 165.

This is strong evidence of numeric-index reuse across templates whose atom ordering differs. It is not, by itself, proof that the deposited fructofuranose restraint is an error; author intent is still required.

## What is `H62` attached to?

In the compiled fructofuranose topology:

- selected atom 165 is hydrogen `H62`;
- `H62` has one heavy-atom neighbour;
- that parent is atom 164, exocyclic carbon `C6`.

Thus replacing index 165 with 164 would produce:

`C2, O5, C5, C6, C4, C3`

This is a connected all-heavy group consisting of the five-member furanose ring plus exocyclic C6. It is one plausible correction hypothesis, not an adopted correction.

## Bounded graph-coherent alternatives

The audit enumerated every selected-ring-adjacent heavy atom that can replace `H62` while preserving a connected five-member cyclic core.

| Hypothesis | Selected group | Graph result |
|---|---|---|
| Omit H62 | `C2,O5,C5,C4,C3` | five ring heavy atoms; connected |
| Replace with C6, atom 164 | `C2,O5,C5,C6,C4,C3` | ring plus exocyclic carbon; connected |
| Replace with O4, atom 171 | `C2,O5,C5,O4,C4,C3` | ring plus exocyclic oxygen; connected |
| Replace with O3, atom 175 | `C2,O5,C5,O3,C4,C3` | ring plus exocyclic oxygen; connected |
| Replace with C1, atom 177 | `C2,O5,C5,C1,C4,C3` | ring plus exocyclic carbon; connected |
| Replace with O1, atom 183 | `C2,O5,C5,O1,C4,C3` | ring plus terminal hydroxyl oxygen; connected |

All six bounded alternatives are all-heavy, connected and retain the five-member furanose ring. Graph consistency alone cannot identify which, if any, represents the authors’ intended centre-of-mass definition.

## Why no automatic correction is made

A corrected restraint cannot be selected safely from topology adjacency alone because different choices alter:

- centre-of-mass position;
- total selected mass;
- pulling direction and initial distance;
- steered-MD work profile;
- generated umbrella path;
- cross-sugar comparability.

The most direct substitution is `H62 → C6` because `C6` is H62’s heavy parent and because glucose and galactose include exocyclic C6. However, fructopyranose uses ring heavy atoms only, so the public inputs do not establish one universal design rule.

No corrected AMBER restraint file is generated by this audit.

## Decision

1. Treat exact reuse of the fructopyranose numeric indices in the fructofuranose template as a likely provenance issue requiring author clarification.
2. Preserve `H62 → C6` and the five-ring-only definition as the two highest-information hypotheses; retain the other graph-coherent alternatives in the machine record.
3. Do not regenerate fructofuranose SMD or umbrella trajectories from any alternative without author confirmation or a preregistered sensitivity study using source coordinates.
4. Do not use the anomaly to alter deposited WHAM outputs retrospectively.
5. Keep parent glucose-versus-PaG calibration and MC-Q1 ranking blocked.
