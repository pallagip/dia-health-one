Research insight · glucose-responsive insulin

Keep the glucose signal.
Reject the interference.

A closer look at why we are testing a small, position-specific change to a published glucose-binding macrocycle—and how the experiment can prove the idea wrong.

Where the work stands: this is a computational design hypothesis. No Dia Health One macrocycle in this set has been synthesized or measured, and none is a smart insulin or a treatment.
The scientific question

A useful sensor must do both.

Binding glucose alone is not enough. A sensor must preserve the desired signal while resisting molecules that can trigger the wrong response.

01 · Published starting point

NNC2215 showed glucose response.

Published work established glucose-responsive activity for the NNC2215 insulin design. Follow-up work reported interference from paracetamol glucuronide (PaG), a paracetamol metabolite.

02 · The rescue question

Can selectivity be designed in?

Our goal is to investigate whether a glucose-binding receptor can retain useful glucose recognition while reducing PaG interaction. This is a question to test, not a result we claim.

03 · Separate the variables

Start with the receptor fragment.

The four planned test articles are free macrocycle fragments: they contain no insulin. Testing these first isolates the host–guest binding question before any later switch or insulin-conjugate work.

Why this edit?

A local hypothesis, not a steric-block claim.

The current design, MC-Q1, changes one roof substituent to methoxy at a site selected by a fixed-coordinate geometry screen. The working mechanism is local polarity, electronics, hydration or solvation—not a claim that the edit physically blocks PaG.

The same edit is also proposed at a distal site as a positional control. If the two positions behave alike, that would argue against the proposed local mechanism.

Minimum experiment

Four comparisons. Four distinct questions.

The point is not to generate a large library. It is to compare designs that can distinguish a site-specific effect from general changes in composition or polarity.

Parent reference
MC-P0Unedited reference. Provides the same-assay baseline for glucose and PaG binding.
Primary hypothesis
MC-Q1Contact-site methoxy edit. Tests whether a local change improves glucose-over-PaG selectivity.
Positional control
MC-Q1DThe same methoxy edit at a distal roof site. Tests whether position matters when composition is held constant.
Constitutional control
MC-P3Contact-site hydroxymethyl edit. Tests whether arrangement, not just polarity, changes the result.

MC-P1, a size-down methyl control, is a possible expansion—not part of the core four-compound set.

Falsifiable comparisons

What would change our minds?

Each comparison has a distinct interpretation. A negative result is useful if it closes a mechanism rather than prompting unbounded redesign.

MC-Q1 vs MC-P0

Does the contact-site edit improve glucose-over-PaG selectivity at all?

MC-Q1 vs MC-Q1D

Is any effect specific to the proposed site, or does the same edit behave similarly elsewhere?

MC-Q1 vs MC-P3

Does the molecular arrangement matter beyond adding a polar group?

Direct binding and controls

Does measured selectivity survive confidence intervals, same-run parent comparison and an orthogonal binding method?

Evidence boundary

What the screen does—and does not—show.

It identifies a model-local geometry worth testing and helps choose a positional control. It does not establish affinity, selectivity, synthesis feasibility, switching behaviour, safety or therapeutic benefit. The current public record reports no calibrated prospective affinity prediction and no candidate-specific measurement.
