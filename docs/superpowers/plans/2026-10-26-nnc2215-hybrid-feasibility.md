> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish a reproducible inventory showing whether standard Amber14SB residue templates cover the insulin sequence and exactly where NNC2215 custom conjugate parameters are still required.

**Architecture:** A standalone Python audit reads the source-derived full graph and Sage coverage ledger, recursively inspects OpenMM's installed `amber14-all.xml` include tree, and writes a deterministic JSON report. Documentation and the research dashboard consume that report without implying a parameterized or simulation-ready force field.

- [ ] **Step 1: Implement recursive Amber XML inventory.** Resolve the OpenMM data directory from `openmm.app.__file__`; start at `amber14-all.xml`; recursively load only declared `<Include file="…"/>` paths under that directory; collect `<Residue name="…">` names and SHA-256 each included XML file. Reject an include that escapes the data directory or a missing include.

  ```python
  def load_amber_templates(root_xml: Path) -> tuple[set[str], list[dict[str, str]]]:
      data_dir = root_xml.parent.resolve()
      root_xml = root_xml.resolve()
      pending = [root_xml]
      visited: dict[str, str] = {}
      names: set[str] = set()
      while pending:
          path = pending.pop()
          path = path.resolve()
          if not path.is_relative_to(data_dir):
              raise ValueError(f"Amber include escapes OpenMM data directory: {path}")
          relative = path.relative_to(data_dir)
          if str(relative) in visited:
              continue
          raw = path.read_bytes()
          visited[str(relative)] = hashlib.sha256(raw).hexdigest()
          xml_root = ET.fromstring(raw)
          names.update(node.attrib["name"] for node in xml_root.iter("Residue") if "name" in node.attrib)
          pending.extend((data_dir / node.attrib["file"]).resolve() for node in xml_root.iter("Include"))
      return names, [{"path": path, "sha256": digest} for path, digest in sorted(visited.items())]
  ```

## Safety and scientific boundary

The inventory reports template names, not OpenMM residue matching or parameter validity. It does not choose a protonation state, assign partial charges, construct a hybrid system, use candidate coordinates, run MD, estimate binding, or support a treatment conclusion. Keep the validated-conjugate-force-field count at zero until a complete, compatible, chemically reviewed parameter set exists.
