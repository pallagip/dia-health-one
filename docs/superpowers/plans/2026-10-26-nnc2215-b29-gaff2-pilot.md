# NNC2215 B29 GAFF2 Parameterization Pilot Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Determine whether pinned AmberTools can generate reproducible candidate GAFF2/AM1-BCC assignments for the source-mapped B29 conjugate in the declared tri-carboxylate charge state.

**Architecture:** A deterministic research audit reconstructs the mapped B29 product, enumerates its eight carboxylate Lewis-label variants, maps the heavy atoms to one documented publisher model-built coordinate candidate, adds explicit hydrogens, runs AmberTools 26 Antechamber and parmchk2 in isolated temporary directories, and records checksums, charge sums, atom types, and parameter gaps. The result remains a feasibility pilot; it does not build a complete insulin residue topology, OpenMM system, or run MD.

**Tech Stack:** Python 3.12, RDKit 2026.03.1, AmberTools 26, GAFF2, AM1-BCC.

### Scope limits

This pilot parameterizes only an isolated source-mapped B29 conjugate fragment. It does not assign final charges to LysB29 or insulin, resolve the model's atom-name ambiguity, parameterize the B1 junction, validate force-field transferability or cross-boundary terms, build a full insulin topology, run molecular dynamics, estimate binding, or imply drug or clinical readiness.
